# MiVoiceMic 介绍视频 · 提纲

> 目标时长 9–10 分钟；平台：B 站 / 视频号 / YouTube 均可。
> 受众：对逆向、Windows 系统编程感兴趣的开发者为主，普通数码用户也能看懂前两幕和演示幕。
> 一句话卖点：**99 元的小米电视遥控器，变成 Windows 的全屋无线麦克风。**

## 录制注意事项

1. **演示按键映射时务必按遥控器上的键**——按物理键盘的同名键会被程序识别为"非遥控器"而正常放行，看起来就像映射没生效（README 已注明）。
2. 开录前先跑 `--check` 确认全绿、`--e2e` 出现 PASS，避免现场翻车；遥控器深度休眠会"失联"，先按一下任意键唤醒。
3. 若输入法识别结果没上屏，先点一下目标输入框——这是微信输入法的焦点要求，不是程序坏了。
4. 讲"未完成"部分时放低语速、语气诚实——这部分恰恰是技术观众最买账的内容。
5. GitHub 仓库地址、BGM、封面图另备；封面建议文案："99 元小米遥控器 × Windows = 全屋无线麦克风"。
