修复安装遥控器内核驱动后，普通键盘 F5 被程序误拦截的问题，同时保留遥控器唤起微信语音输入的行为。

- 程序启动和遥控器连接时检查驱动是否实际运行；驱动运行时只拦截遥控器的 F20，放行键盘 F5 的按下、重复和松开。
- 驱动模式下，语音开始前只清理 F20 状态，避免额外释放正在按住的 F5。
- 旧配置中的语音键 F5 映射不再误捕获普通键盘 F5。

此修复适用于 `MiRemoteHidFilter` 已运行的情况。未运行驱动时，遥控器仍发送 F5，程序保留原来的 F5/F20 兼容拦截行为。

下载说明：

- **首次使用：**下载 `MiVoiceMic-v1.0.2-win-x64.zip`，完整解压后运行 `MiVoiceMic.exe`。
- **从 v1.0.1 更新：**从托盘退出旧程序，下载并替换 `MiVoiceMic.exe` 即可。已有配置继续使用，无需重新安装驱动。
- `SHA256SUMS.txt` 用于核对 EXE 和压缩包的完整性。

适用于 Windows 10 / 11 x64，需要 .NET Framework 4.8 和 VB-CABLE。验证：106 项应用自检通过，用户实测确认键盘 F5 和遥控器微信语音输入均正常。
