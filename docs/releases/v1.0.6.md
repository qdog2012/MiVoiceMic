## 修复与改进

- 新增 **连接与语音 → 音频与增益 → 选择音频设备**，可从本机设备列表选择虚拟声卡的播放端、录音端，刷新列表并立即应用、保存，无需重启程序。
- 解决本机播放端名为 `CABLE In 16 Ch`、旧配置仍为 `CABLE Input` 时，热键图标和调试录音正常但声音未送入输入法的问题。请在新窗口中选择同一条虚拟声卡的两端。
- 界面选择后保存设备标识，设备改名或列表顺序变化后仍可定位原设备；兼容旧版名称配置，设备缺失或名称不唯一时明确提示重新选择。
- 应用新设备前先验证能否打开音频输出；打开或保存失败时保留原设置和音频输出。说话期间会提示先松开语音键。
- 环境自检改为核对配置的实际设备和程序音频输出状态，不再仅凭设备名称包含 `CABLE` 就报告就绪。
- 修复测试音一次性入队及音频块截断造成的丢失，改为完整发送 1 秒音频；改善音频缓冲清理、错误提示和配置文件保存。

## 验证

- 157 项离线自测通过。
- 本机验证虚拟声卡回录，以及设备切换、配置恢复、失败时保留原设置等 14 项集成检查。
- 检查音频设备窗口在 100% 和 150% 缩放下的布局。

## 更新方式

- 已有用户可在 **关于 → 检查更新** 中下载并更新，保留现有配置和驱动。
- 也可下载 `MiVoiceMic.exe` 覆盖原程序；首次使用建议下载完整的 Windows x64 ZIP 包。
- 安装或更新后若提示设备不可用，请打开 **选择音频设备**，按本机实际名称选择播放端和录音端并应用。
