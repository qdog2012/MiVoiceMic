## 新增与改进

- 系统托盘图标直接显示遥控器剩余电量数字，例如 `61` 表示 61%。悬停可查看完整百分比、充电状态和连接状态。
- 图标使用颜色区分状态：正常为蓝色，16–30% 为橙色，0–15% 为红色，充电时为绿色。
- 电量读取中显示 `?`，断开连接显示 `×`；重新连接后等待新的电量报告，避免继续显示旧电量。
- 图标随遥控器电量、充电和连接状态更新，兼顾浅色与深色任务栏背景。电量未变化时复用图标，替换和退出时释放相关资源。

## 验证

- 157 项离线自测通过。
- 10 项托盘针对性检查通过，覆盖初始显示、电量和充电变化、断连与重连、提示文本长度和资源释放。
- 连续生成并释放 500 个图标，未发现 USER 图标句柄增长。
- 检查 16、24、32 像素图标在浅色和深色背景下的显示效果。

## 更新方式

- 已有用户可在 **关于 → 检查更新** 中下载并更新，保留现有配置和驱动。
- 也可下载 `MiVoiceMic.exe` 覆盖原程序；首次使用建议下载完整的 Windows x64 ZIP 包。
- 若 Windows 将图标折叠在任务栏的“∧”菜单中，可将其拖到通知区域常驻显示。
