## 改进

- 环境自检新增“遥控器连接状态”，分别显示蓝牙是否已连接、程序语音通道是否已就绪，避免将“已配对”误认为“已连接”。
- 页面打开时每 3 秒刷新连接状态；未连接、语音通道未就绪、系统状态读取失败或状态不一致时，会显示对应提示。
- 检测只读取系统连接状态，不主动重连遥控器。
- 自检结果支持长文本换行和滚动，小窗口也能查看完整提示。
- 命令行 `--check` 同样检查系统蓝牙连接；语音通道是否就绪以主程序为准。

## 更新方式

- 已有用户可在“关于 → 检查更新”中下载并更新，保留现有配置和驱动。
- 也可下载 EXE 覆盖原程序；首次使用建议下载完整的 Windows x64 ZIP 包。
