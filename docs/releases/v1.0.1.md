- **首次使用：**下载 `MiVoiceMic-v1.0.1-win-x64.zip`，完整解压后运行其中的 `MiVoiceMic.exe`。压缩包包含驱动安装脚本和使用说明。
- **更新已有程序：**下载 `MiVoiceMic.exe`，从托盘退出旧程序后替换；已有 `config.json` 可继续使用。需要新的驱动安装修复时，请同时更新完整压缩包中的 `driver` 文件夹。
- `SHA256SUMS.txt` 用于核对 EXE 和压缩包的完整性。

适用于 Windows 10 / 11 x64，需要 .NET Framework 4.8 和 VB-CABLE。使用微信语音输入时，程序热键应与微信输入法设置保持一致。普通语音使用无需安装内核驱动；扩展遥控器按键所需的驱动是测试签名版本，安装条件见随包说明。
