## 修复与改进

- 修复“固定增益”滑条拖动后 dB 数值延迟显示的问题。拖动时立即刷新具体数值和 AGC 状态，无需等待电量或连接状态更新。
- 增益在拖动过程中实时生效，松开鼠标后保存一次配置，避免每次移动鼠标都写文件、重新配置热键和按键映射。
- 鼠标移出滑条后松开或失去鼠标捕获时，也会保存最终增益；右键点击不会修改增益。

## 验证

- 157 项离线自测通过。
- 12 项针对性检查通过，覆盖正负 dB 显示、卡片和 AGC 重绘、增益实时应用、松开保存及边界拖动。

## 更新方式

- 已有用户可在 **关于 → 检查更新** 中下载并更新，保留现有配置和驱动。
- 也可下载 `MiVoiceMic.exe` 覆盖原程序；首次使用建议下载完整的 Windows x64 ZIP 包。
